# 虚构示例项目

本目录演示“新资料进入项目上下文，再生成每日推进”的最小过程。所有名称、角色、日期和状态均为虚构。

建议按以下顺序阅读：

1. `project-goal.md`：项目目标、里程碑和验收条件。
2. `shared-context.md`：上一次同步后的当前状态。
3. `new-evidence.md`：今天收到的新资料，其中既有记录，也有尚未确认的变更提议。
4. `daily-advancement-example.md`：基于前三份资料形成的项目经理推进项示例。

练习时可以先用 `sync-project-context` 做“影响评估”，确认哪些内容应更新；再使用 `prompts/daily-advancement.md` 生成当天推进项。
